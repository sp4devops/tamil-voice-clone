# Security Policy

## Reporting a vulnerability

Please avoid publishing exploitable vulnerabilities in a public issue before a fix is available. Use GitHub's private security-reporting path when available; otherwise contact the maintainer privately through the GitHub profile linked to this repository.

Include the affected component, reproduction steps, expected impact, and any suggested mitigation.

## Sensitive data

Voice-cloning workflows can involve private voice recordings, transcripts, model artifacts, generated personal audio, and credentials. Never commit or attach private voice material, tokens, credentials, or personally sensitive generated artifacts to public issues, pull requests, or CI artifacts.

## Supported code

Security fixes target the current `main` branch and the accepted Stage-1 baseline. Historical experimental branches may not receive fixes.
