# Changelog

All notable project milestones are documented here.

## Stage 1 accepted baseline — 2026-08

Initial public OSS research milestone.

Highlights:

- local zero-shot Tamil, English, and Tanglish voice-cloning workflow;
- one-model speaker-identity strategy across Tamil and English;
- Apple Silicon validation under the 3 GiB RSS target;
- human-accepted Stage-1 speaker similarity milestone;
- reproducible workflow evidence for memory and language checks;
- MIT licensing and public contribution/security documentation.

This repository is a research baseline rather than a packaged semantic-version release. The accepted Stage-1 state is intentionally kept stable while audiobook work proceeds separately.
